# NeoSky Service & Support

Production Android app + backend for NeoSky/TAS drone customers to manage
service tickets, flight logs, warranty, maintenance, invoices, and documents
for their registered drones.

See the `claude/wizardly-goodall-waijwd` branch / open pull request for the
current build (Kotlin/Jetpack Compose Android app + FastAPI backend +
PostgreSQL schema). This repository was just created; full project docs land
with that PR.
